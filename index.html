Auth — shared by every module
Add module
A module is one API area: its own cases, its own OpenAPI spec, its own run history and its own host. The environment, token and settings stay shared, so switching modules doesn't make you set up again.
Once it's created, load its spec with Spec for this module, or bring its cases in with Import (CSV / JSON / Google Sheet).
Settings
This module
The host this module uses in the current environment. Leave it empty to fall back to the shared default for its service. Switching environments swaps this automatically — that's why there's no Base URL box in the top bar any more.
Running
Leave this empty for Stage and Local — the Swivl stage API already returns Access-Control-Allow-Origin: *, so the browser can call it directly from anywhere.
Browsers block cross-origin API calls from file:// pages. If your API doesn't allow CORS from your origin, set a proxy URL here (e.g. https://corsproxy.io/?) and requests will be routed through it. Leave blank if your API already returns the right CORS headers, or if you run this page behind your own dev server.
Heads up: public proxies like corsproxy.io and allorigins.win only forward GET. For POST/PUT/PATCH/DELETE, either clear this field or host your own proxy.
How long any one case may hang before it's called a failure. This is the single biggest lever on run time — two cases parked on a 30 s timeout cost more than the other hundred combined. Timing and load cases ignore it and use the ceiling below.
How many requests are in flight at once. Set to 1 for the old strictly-sequential behaviour. Cases about response time, rate limiting or concurrent load are always pulled out and run alone at the end, so a busy pool can't invalidate them.

Use the built-in Swivl Template API spec
All real endpoints (Templates, Sections, Items, Submissions, Categories, Health) — sample bodies and x-api-version pre-filled. No network needed.

Or paste your API's docs URL and hit Connect. The app fetches the spec, fills every matching test case with the documented query params, path vars, headers, and example request body — and checks every live response against the spec.

Works with raw JSON (/api-docs/json, /openapi.json), Scalar/Swagger UI pages, and plain docs URLs. If the browser blocks it, set a CORS proxy in Settings ⚙.

Import test cases

Upload a file, paste a Google Sheets link, or paste rows directly. Columns (case-insensitive): id, scenario, method, path, tag, expectedStatus, body, notes. Tab-separated (Google Sheets copy) and comma-separated both work. JSON accepts an array of test-case objects.

Paste the Google Sheets link. If your workbook has multiple tabs, click the tab in Google Sheets first — the URL will change to include #gid=123456; paste that full URL here, or type just the gid into the box on the right. The sheet must be shared as "Anyone with the link: Viewer". Hits CORS? Set a proxy in Settings ⚙.
